Microsoft, San Francisco’daki Build 2026 geliştirici konferansında kendi yapay zekâ model ailesini genişletti. Şirket, yazılı komutlardan uygulama ve web sitesi kodu üretebilen MAI-Code-1-Flash ile akıl yürütme görevlerine odaklanan MAI-Thinking-1 modelini duyurdu.

Duyuru, Microsoft’un yapay zekâ yarışında yalnızca OpenAI ve Anthropic modellerini Azure üzerinden sunan bir altyapı sağlayıcısı olmaktan çıkıp model katmanında da daha güçlü bir oyuncu olma isteğini gösteriyor. Şirket, kendi modellerini kendi bulut altyapısında çalıştırarak üçüncü taraf model maliyetlerini azaltmayı ve bu avantajı geliştiricilere yansıtmayı hedefliyor.

Microsoft yöneticileri, yeni modellerin özellikle verimlilik ve düşük kullanım maliyeti için tasarlandığını vurguladı. MAI-Thinking-1, Microsoft Foundry üzerinden özel ön izlemeye açılırken, müşterilerin kendi verilerini ekleyerek modelin doğruluğunu artırabileceği belirtildi.

Kodlama modeli MAI-Code-1-Flash ise GitHub Copilot ve Visual Studio Code içinde kullanılabilecek. Microsoft ayrıca konuşma tanıma, sentetik ses, görsel üretim ve Windows bilgisayarlarda çalışabilecek küçük Aion modelleri için de güncellemeler açıkladı.
